UC Berkeley D-Lab's 6-part, 12-hour introduction to Python, with a focus on data science applications. No prior programming experience required.

## Workshop Structure

Each part takes 2 hours, delivered as a lecture-style coding walkthrough with challenge problems and a break.

1. **Part 1** — Introduction to Jupyter and Python
2. **Part 2** — Data Types and Structures
3. **Part 3** — Introduction to Pandas
4. **Part 4** — Functions and Conditionals
5. **Part 5** — Data Analysis and Visualization
6. **Part 6** — Project

Parts 1–3 cover the basics of Python/Jupyter, variables and data types, and a gentle intro to Pandas. Parts 4–6 cover loops/conditionals, writing functions, Pandas-based analysis and visualization, and the overall workflow of a data science project.

## Learning Objectives

- Navigate Jupyter Notebooks
- Assign variables
- Distinguish common data types and structures
- Apply methods to data types
- Inspect documentation to deal with error messages
- Implement loops for repeated computations
- Understand how to handle conditions
- Write your own functions
- Perform basic operations in Pandas, including visualization
- Understand the basic workflow of a data science project

## Out of Scope

## Installation & Setup

1. [Download and install Anaconda](https://www.anaconda.com/products/individual) (recommended: Python 3.12+, included by default in the latest Anaconda distribution).
2. Download the repo (green "Code" button → "Download Zip") or clone it: `git clone https://github.com/dlab-berkeley/Python-Fundamentals.git`
3. Open Anaconda Navigator → launch Jupyter Lab → navigate to the `Python-Fundamentals` folder → `lessons/Fundamentals-I/01_Jupyter_and_Python.ipynb` to begin.
4. Run cells with Shift+Enter (or Ctrl+Enter).
